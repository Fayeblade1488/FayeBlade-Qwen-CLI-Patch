# Contributing

Contributions are welcome! Please read these guidelines before contributing.

## Development Environment
1. Clone the repository.
2. Create a virtual environment: `python -m venv .venv`
3. Activate the virtual environment: `source .venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`

## Commit Style
We use Conventional Commits. Please format your commit messages as follows:
`feat: add new feature`
`fix: fix a bug`
`docs: update documentation`
`chore: update build scripts`

## Branch Naming
Please use the following format for your branch names:
`type/scope-short-desc`
Example: `feat/api-add-new-endpoint`

## Pull Requests
- All pull requests must be reviewed by at least one other person.
- All pull requests must pass all CI checks.
