# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities to our private email address: security@example.com

We will do our best to respond within 24 hours.

## Dependency Update Policy

We update our dependencies on a regular basis. All dependencies are scanned for vulnerabilities before being updated.
